#### Description

This pull request introduces the following changes:

1. **GitHub Actions CI Workflow**:
   - Added steps to set up Rust environment, build the Rust project, and run tests.
   - Integrated Racket setup alongside Rust for building and testing `rkt-polars`.
   - Added steps to copy the shared library object using a Racket script.

2. **Makefile**:
   - Created a `Makefile` to streamline the build process with targets for building, cleaning, and copying the shared object.

3. **Rust Integration**:
   - Added a new Rust library under `compat/` with a simple `add` function and corresponding tests.
   - Created `Cargo.toml` for managing Rust dependencies and project settings.

4. **Racket Integration**:
   - Updated `main.rkt` to use Racket's FFI to interface with the Rust library.
   - Added `copy-lib.rkt` to automate the process of copying the compiled shared library to the appropriate directory.

5. **Documentation**:
   - Enhanced `README.md` with a brief description of the project.

6. **.gitignore**:
   - Updated `.gitignore` to exclude build artifacts and user-specific files for both Rust and Racket projects.

#### Impact

- This PR enables seamless interplay between Rust and Racket, allowing Racket to utilize Rust-compiled libraries.
- The CI pipeline ensures that the project builds and tests correctly on each push and merge, increasing reliability and reducing manual testing efforts.
- The `Makefile` provides an easy-to-use mechanism for developers to build and clean the project.

#### Testing

- CI pipeline runs comprehensive tests for both Rust and Racket components.
- Local `make` commands ensure that all targets perform as expected.

#### Notes

- Future enhancements could include more complex Rust functions exposed via FFI and additional tests to ensure robustness.
